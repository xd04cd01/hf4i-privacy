HF4I Privacy Policy / Chính sách quyền riêng tư

Service: MVS – Trợ lý vận hành hệ thống báo cáo thi công (HF4I)

Tiếng Việt

Trang này mô tả cách GPT Action của hệ thống HF4I xử lý dữ liệu khi kết nối tới Cloud Run Gateway.

  • Dữ liệu chỉ được gửi tới Cloud Run Gateway của HF4I để xử lý theo yêu cầu.
  • Gateway kiểm tra phân quyền trước khi trả dữ liệu.
  • Không tự động ghi dữ liệu nghiệp vụ nếu chưa có xác nhận và quy trình backend phù hợp.
  • Thông tin xác thực được bảo vệ bằng API Key và cơ chế phân quyền phía máy chủ.
  • Hệ thống chỉ xử lý dữ liệu cần thiết cho yêu cầu của người dùng.

English

This page describes how the HF4I GPT Action handles data.

  • Requests are sent only to the HF4I Cloud Run Gateway.
  • Server-side authorization is enforced before data is returned.
  • No business data is automatically committed without the appropriate backend workflow.
  • Authentication is protected using an API key and server-side permission checks.
  • Only the minimum data required to fulfill the request is processed.
